# listen-with-vibes
listen anything with vibes, built with Html,css,js,ts

# what it is
this is a frontend for a player app for playing media files , this does not contain the player logic or player, it just contains the frontend and css programs. the idea was to make a phone first app with web technologies.

# features
- optimised for phone and desktop at the same time
- bare bones frontend only
- it contains modals , popups, etc
- it contains themes, button themes
- made with html , css ,js and ts this project in its own is barebones and written in mostly vanila js and ts
- can be used to make apps for phones based on web technologies
